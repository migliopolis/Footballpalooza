# FBP Rookie Pricer

Live at https://migliopolis.github.io/Footballpalooza/rookie-pricer/

Owners pick their FBP draft slot and see what each rookie would cost there.

## Files

- `index.html`: the page. It reads the two JSON files below.
- `pricing.json`: the salary formula (position max, NFL curve, FBP curve, $3 minimum, escalators). Change a number here and every price updates.
- `players.json`: the rookie class the page shows. Generated by `build_players.py`; don't hand-edit unless it's a quick fix.
- `sources.json`: the mocks and big board behind `players.json`.
- `build_players.py`: rebuilds `players.json` from `sources.json`.

## Updating the mocks

1. Edit `sources.json`: replace or add entries in `rookieMocks` (ordered pick lists), `nflMocks` (player → overall pick), and `bigBoard` (player → rank). Add any new player's position to `positions` and school to `schools`. Update `asOf`.
2. Run `python3 build_players.py` from this folder.
3. Commit `sources.json` and `players.json`. GitHub Pages rebuilds in a minute or two.

How the averaging works is described at the top of `build_players.py`.

## After the NFL draft

Add an `"actualNflPicks"` map to `sources.json` (player → real overall pick), set `"mode": "final"`, and rerun the script. The "Projected" label disappears from the page.

## Price formula

Price = position max × NFL factor × FBP factor, rounded to the nearest dollar, with a $3 minimum in rounds 1–2. Rounds 3 and 4 are flat at $2 and $1.
